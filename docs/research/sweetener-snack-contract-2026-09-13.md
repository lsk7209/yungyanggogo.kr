# 대체당간식 계약 검토 — 2026-09-13

## 결정

`phase6t-sweetener-snack-basis`는 `research_needed`로 보류한다. 네 개 하위 변형도 이 계약 뒤에서 보류하며 공개·초안 작성·승인 대상으로 취급하지 않는다.

## 제품 범위 문제

생성 글의 `대체당간식`은 다음 범위를 구분하지 않는다.

1. 당류가 상대적으로 낮은 간식
2. 무당·무설탕·제로슈거 강조표시가 있는 간식
3. 특정 감미료를 사용한 간식

이 범주는 서로 겹칠 수 있지만 같은 의미가 아니다. 제품 종류와 표시 문구, 원재료, 영양성분을 분리해 확인해야 한다.

## 기존 계약과의 경계

- `low-sugar-snack-*`는 가공간식의 당류와 100g 분모 비교를 소유한다.
- `no-sugar-label-*`는 제품군 전반의 무당·제로슈거·감미료 표시 해석을 소유한다.
- `zero-sugar-drink-*`는 음료의 100ml와 감미료 비교를 소유하므로 간식의 병합 대상이 아니다.

현재 글은 간식별 제품 계약과 표시 해석 계약을 섞고 있어 어느 기존 소유자에도 안전하게 병합할 수 없다.

## 연구 하드 게이트

1. 저당 간식, 무설탕 표시 간식, 대체감미료 간식 중 독자 범위를 하나로 고정한다.
2. 복수의 현재 판매 포장 제품과 최신 라벨을 확보한다.
3. 제품 유형, 1회 제공량, 총내용량, 당류, 열량, 감미료명과 원재료 순서를 기록한다.
4. 표시기준 해석과 영양성분 비교를 서로 다른 근거 층으로 분리한다.
5. 제품 리뉴얼과 확인 날짜를 남긴다.

질병, 혈당, 체중감량, 어린이 안전성 또는 특정 감미료의 우월성을 주장하지 않는다. 제품군과 분모가 다른 수치를 순위화하지 않는다.

## 검색·공개 상태

Naver 관찰이나 수요·순위 확인은 수행하지 않았다. 제목과 키워드는 선택하지 않는다. 현재 상태는 `research_needed`, `humanReview: pending`, `noindex: true`이며 공개 로더 밖에 둔다.
