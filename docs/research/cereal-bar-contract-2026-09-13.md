# 시리얼바 계약 검토 — 2026-09-13

## 결정

`phase6t-cereal-bar-basis`는 기존 글에 병합하지 않고 `research_needed`로 보류한다. 공개·초안 작성·승인 대상으로 취급하지 않는다.

## 독립적인 독자 결정

독자는 바쁜 아침이나 간식 상황에서 한 개짜리 시리얼·스낵바를 고른다. 이때 필요한 결정은 정확한 1개 중량과 표시 기준을 맞춘 뒤 당류와 지방을 같은 제품군 안에서 비교하는 것이다. 식이섬유·통곡물 문구는 실제 라벨과 원재료 근거가 있을 때만 보조 항목으로 사용할 수 있다.

## 기존 계약과의 경계

- `protein-bar-fat-basis`와 `phase6t-protein-bar-basis`는 단백질을 먼저 보고 포화지방·당류를 보조로 읽는 프로틴바 계약이다.
- `granola-fat-basis`와 `phase6t-granola-basis`는 그릇형 그래놀라의 1회 제공량, 견과 토핑, 지방·당류 계약이다.
- 시리얼바는 한 개 단위의 중량과 개별 포장 표시가 핵심이라 위 계약에 그대로 합치면 독자의 실제 비교 단위가 사라진다.

## 연구 하드 게이트

초안 작성 전 다음 자료가 모두 필요하다.

1. 현재 판매 중인 복수의 실제 시리얼바 또는 그래놀라바 제품 식별 정보
2. 각 제품의 정확한 1개 중량, 총내용량, 포장당 제공 횟수
3. 같은 기준으로 비교 가능한 당류·지방·식이섬유 표시값
4. 통곡물·곡물·견과 등 앞면 문구를 검증할 수 있는 원재료명과 함량 표시
5. 제품 리뉴얼 여부와 확인 날짜

제품군, 중량, 표시 기준이 다른 숫자는 바로 순위화하지 않는다. 라벨이 없는 제품에 평균값을 대입하지 않으며, 아침 식사 대체·체중 관리·질병 예방 효과를 주장하지 않는다.

## 현재 근거 한계

기존 Phase 6T 글은 일반 식품영양 데이터베이스 링크만 공유하며, 특정 제품명·1개 중량·제공 횟수·현재 포장 라벨을 제시하지 않는다. 따라서 제품 간 비교나 추천을 뒷받침하지 못한다.

## 검색·공개 상태

별도 Naver 관찰이나 검색 수요 확인은 수행하지 않았다. 제목과 키워드는 선택하지 않는다. 상태는 `research_needed`, `humanReview: pending`, `noindex: true`이며 공개 로더 밖에 둔다.
