# 운영 반영 및 롤백

## 운영 반영 전제

- 현재 변경은 로컬 코드/문서뿐이며 배포·DB 쓰기·계정 변경은 하지 않았다.
- CI와 preview에서 parser/public-copy/typecheck/lint/build/HTTP 검사를 재실행한다.
- 운영 환경변수 값은 로그에 출력하지 않고 설정 여부와 실제 응답만 확인한다.
- 콘텐츠·광고·법정 주장 관련 변경은 담당자 검토를 별도로 기록한다.

## 중단 조건

- 기존 실제 데이터 검색 또는 상세 URL 회귀, sitemap에 noindex/404 포함, 비밀값 노출, 신규 빌드 실패.

## 롤백

- 코드 롤백: 이 작업의 선택 파일만 정상 Git revert로 되돌린다. 작업 전 dirty 파일 전체를 reset하지 않는다.
- 코드 롤백 순서: 공개 라우트/UI → 비교·선택 모듈 → DB 검색/캐시 → 공통 파서·fetch helper 순으로 의존 소비자를 먼저 되돌리고, 각 단계에서 typecheck와 관련 회귀 스크립트를 실행한다.
- 데이터 롤백: 이번 작업은 DB 쓰기/마이그레이션이 없어 해당 없음.
- 운영 롤백 검증: 배포하지 않았으므로 NOT RUN.
