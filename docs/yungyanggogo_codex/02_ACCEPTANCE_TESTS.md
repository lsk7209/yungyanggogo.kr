# 영양고고 개선 — 수용 테스트와 완료 판정

기준일: 2026-09-12
사용법: `01_MASTER_PROMPT.md`의 요구를 현재 저장소에 맞는 단위·통합·브라우저·HTTP 검사로 구현한다. 이 문서는 테스트 명세이며 실행 결과가 아니다. 아래 항목은 모두 초기 상태 `NOT RUN`이다.

## 1. 결과 기록 계약

각 테스트에 다음을 기록한다.

`test_id, environment, command_or_steps, fixture_or_url, expected, actual, status, evidence_path, checked_at, limitation`

상태는 `PASS`, `FAIL`, `NOT RUN`, 근거가 있는 `NOT APPLICABLE`만 사용한다. 도구가 없거나 권한이 없으면 `NOT RUN`이다. CI 설정을 만들었다는 이유만으로 테스트를 실행한 것으로 기록하지 않는다.

합성 fixture는 테스트 전용이다. 아래 입력을 실제 판매 제품이나 사이트 실데이터로 게시하지 않는다.

## 10. 정책 조합 예시

1. 가이드 `published + human_reviewed`, 내용 정상 → index 후보, 광고는 별도 조건 검사.
2. 실제 식품 정보가 있지만 품질 보완 중 → 공개 활용 가능 여부와 noindex·광고 차단을 별도 판정.
3. 검수 원고 → 실제 비공개/인증, sitemap 제외, 광고 없음.
4. API 정상 빈 검색 결과 → 사용자 빈 상태, 기본 noindex, 광고 없음.
5. upstream 장애이나 정상 스냅샷 존재 → 원천/수집 시점을 표시한 대체 제공; 무조건 404/내용 삭제 금지.
6. 부존재 식품 ID → 실제 404, 광고 없음, sitemap 제외.
7. 의도가 같은 글의 통합 완료 → 영구 redirect, 최종 URL 200, 원본 보존, 기존 내부링크 갱신.
8. 정상 목록 page 2 → 자기 canonical과 따라갈 수 있는 링크; 검색 파라미터라는 이유만으로 무조건 noindex 금지.

- **기술 검증:** 실제 실행한 테스트와 남은 환경 제한은 무엇인가?
- **운영 반영:** 명시적으로 승인받아 반영했으며 실제 도메인에서 검증했는가?
- **콘텐츠·심사 준비:** 사람 검수, 광고 계정 상태, 실제 크롤러 접근, 권리·고지가 확인되었는가?

각 항목을 따로 판정한다. 이 체크리스트 통과는 Google의 승인 약속이 아니다.
