# 영양고고 Codex 전달 패키지

작성 기준: 2026-09-12

## 파일

- `01_MASTER_PROMPT.md`: 전체 개선 명세. 범위·재확인·데이터·기능·콘텐츠·SEO·광고·검증·롤백을 포함한다.
- `02_ACCEPTANCE_TESTS.md`: 테스트 입력과 통과 조건. 실제 테스트를 실행한 결과가 아니다.
- `03_START_PROMPT.txt`: 위 두 문서를 함께 제공한 뒤 Codex에 입력할 시작 지시문.

## 전달

영양고고 저장소에서 Codex를 열고 위 파일을 첨부하거나 Codex가 읽을 수 있는 로컬/저장소 문서 경로에 놓은 뒤 `03_START_PROMPT.txt`의 내용을 입력한다. 저장소에 추가한다면 기존 문서를 덮어쓰지 않는다.

본문 전체를 `AGENTS.md`에 덮어쓰지 않는다. 기존 AGENTS 지침을 보존하고 이 명세를 별도 작업 문서로 읽게 한다.

## 범위

이 패키지는 실제 사이트를 수정하거나 운영 계정에 접근한 결과물이 아니다. 공개 페이지와 Google·WHO 등 공식 문서를 확인해 작성한 실행 지시서다. 저장소·DB·Search Console·AdSense 계정 내부는 Codex 작업에서 권한 범위에 맞게 확인해야 한다.

운영 데이터 삭제·운영 배포·계정 설정 변경은 기본 허용 범위가 아니다. 코드와 테스트를 작업 브랜치에서 준비하고 승인된 운영 반영 절차를 별도로 따른다.

## 핵심 보정

DB 레코드 수와 URL 수는 다르다. noindex와 광고 적합성은 별개다. 일정 글 수를 Google 승인 기준으로 단정하지 않는다. 데이터 수가 많다고 자동으로 저품질로 판정하지 않는다. 실제 사람 검수와 AI의 자료 확인을 구분한다.
